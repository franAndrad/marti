# marti 🖤🍕🩺

Una pagina simple hecha con [Astro](https://astro.build) y [GSAP](https://gsap.com)
para Martina: una mezcla de terror, pizza y medicina, con un mensaje de que
todo va a estar bien.

## Desarrollo local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Publicación

El sitio se publica automáticamente en GitHub Pages con GitHub Actions
(`.github/workflows/deploy.yml`) en cada push a `main`.

Para habilitarlo la primera vez: en el repo de GitHub, ir a
**Settings → Pages → Source** y elegir **GitHub Actions**.

El sitio queda disponible en `https://<usuario>.github.io/marti/`.
